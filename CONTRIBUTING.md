# Contribution Guidelines

Thank you for your interest in contributing! Contributions of all kinds are welcome and help make this Awesome List more useful for the Arc community.

Please note that this project adheres to the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you agree to abide by its terms.

---

## What You Can Contribute

Contributions of all kinds are welcome, including but not limited to:

* New Arc ecosystem projects
* Developer tools and infrastructure
* Tutorials, guides, and learning resources
* Research papers and technical resources
* Example projects and starter templates
* Community projects (see below)
* Broken link fixes
* Grammar, formatting, or documentation improvements

## Community Project Submission Guidelines

To keep this list curated and useful for developers, community projects should meet the following criteria:

- Is relevant to the Arc ecosystem.
- Has been showcased to the Arc team.
- Adds value to developers or the community.
- Is not already listed in this repository.
- Includes a concise, objective one-line description.
- Avoids promotional or marketing language.
- Links to a working, publicly accessible repository.

## How to Contribute

For significant additions or structural changes, please open an issue first so we can discuss your proposal. Minor fixes, such as typo corrections, broken links, or formatting improvements, can be submitted directly as pull requests.

To contribute:

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes while following the existing formatting and writing style.
4. Commit your changes with a clear, descriptive commit message.
5. Push your branch to your fork.
6. Open a pull request and clearly describe your changes and the reasoning behind them.

Pull requests will be reviewed as soon as possible. Thank you for helping improve this Awesome List!
